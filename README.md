# SI팀 휴가 캘린더

달력에서 그날 누가 휴가인지만 본다. 사이트에서 바로 등록하면 그 사이트를 보는 사람 전원에게 반영된다.
구글 시트나 외부 서비스 없이 **사이트 자체가 저장소**다.

| 파일 | 용도 |
|---|---|
| `index.html` | 화면 전체 (한 파일) |
| `data.js` | 2026 공휴일 표 + 저장소에 연결 안 될 때 보여줄 예시 목록 |
| `netlify/functions/leaves.mjs` | 휴가 목록 API (Netlify Blobs 에 저장) |
| `netlify.toml`, `package.json` | 배포 설정 |
| `test_leaves.mjs` | 서버 입력 검사 테스트 |
| `시안_8종.html` | 디자인 시안 비교용. 확정됐으면 지워도 된다 |

주말·공휴일은 전원 휴무이므로 그 칸에는 휴가자를 표시하지 않는다.

---

## 배포

```bash
npm install
npx netlify deploy --prod
```

처음이면 `npx netlify login` → `npx netlify init` 로 사이트를 만든 뒤 위 명령을 실행한다.
Netlify Blobs 는 사이트에 기본 포함이라 따로 만들 것이 없다.

배포되면 팀즈 채널 → `+` → **웹사이트** 탭 → 배포된 주소.
`netlify.toml` 이 검색 노출만 막고 iframe 임베드는 열어두므로 탭 안에서 그대로 뜬다.

---

## 쓰기 권한 (읽고 넘어갈 것)

배포된 주소에는 로그인이 없다. 즉 **주소를 아는 사람은 보는 것도, 등록·삭제도 된다.**
사내에서만 도는 주소라면 그대로 써도 되고, 잠그려면 환경변수 하나만 넣는다.

Netlify 사이트 설정 → Environment variables →

```
TEAM_PASSCODE = 팀에 공유할 암호
```

넣으면 등록·삭제할 때 암호를 한 번 묻고, 그 탭에서는 기억한다(보기는 암호 없이 된다).
안 넣으면 암호 없이 누구나 쓸 수 있다.

---

## 쓰는 방법

- **등록** — 상단 `휴가 등록` 버튼, 또는 달력에서 **날짜 칸을 클릭**하면 그 날짜로 폼이 열린다.
  이름·시작·종료(생략하면 하루)·메모를 넣고 등록. 등록한 달로 화면이 넘어가고 칩이 튕겨 들어온다.
- **삭제·수정** — 이름 칩을 클릭하면 확인 후 삭제된다. 수정은 삭제하고 다시 등록한다.
- 다른 사람이 올린 건 **1분마다** 자동으로 반영된다.

---

## 공휴일

`data.js` 의 `holidays` 에 2026년분이 들어 있다(대체공휴일·근로자의날 포함).
해가 바뀌면 이 표만 갱신한다.

---

## 검증

```bash
node test_leaves.mjs
```

서버 입력 검사(없는 날짜, 종료일 역전, 이름·메모 길이, 1년 초과)를 확인한다.

화면 쪽은 브라우저 콘솔에서 `selftest()` — 격자 배치, 월 경계, 휴무일 처리,
색 배정 간격, 파스텔 여부, 폰트·이징 적용을 한 번에 본다. 로직을 고쳤으면 둘 다 돌린다.

---

## 알려진 한계

- 목록을 blob 한 개에 담아 읽기-수정-쓰기 한다. 두 사람이 **같은 순간**에 등록하면 뒤엣것이
  앞엣것을 덮을 수 있다(10명 규모에선 사실상 안 일어남). 문제가 되면 레코드별 키로 쪼갠다 —
  `leaves.mjs` 주석에 적어뒀다.
- 배경 셰이더는 탭이 비활성이거나 8초간 입력이 없으면 렌더를 멈춘다. 노트북 배터리를 계속
  태우지 않기 위한 것이고, 마우스를 움직이면 즉시 되살아난다.
